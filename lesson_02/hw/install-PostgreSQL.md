Цель: научиться подключаться к серверу, создавать базу данных и таблицу, заполнять и просматривать записи — всё через графический интерфейс pgAdmin 4.
Инструмент: pgAdmin 4 (устанавливается вместе с PostgreSQL).

### Задание 1. Подключение к серверу

   1. Откройте pgAdmin 4 (Пуск → PostgreSQL → pgAdmin 4).
   2. При первом запуске может появиться окно ввода пароля — введите пароль, заданный при установке PostgreSQL.
   3. В левой панели раскройте дерево: Servers → PostgreSQL. Если мастер-пароль pgAdmin спросит — введите тот же пароль.

Результат: вы видите дерево объектов сервера (Databases, Roles, Tablespaces и т.д.).

### Задание 2. Создание базы данных

   1. В левой панели нажмите правой кнопкой мыши на Databases → Create → Database.
   2. В открывшемся окне на вкладке General:
   1. Поле Database — введите practice1.
   3. Нажмите Save.
   4. Нажмите правой кнопкой на Databases → Refresh — появится practice1.

Результат: база данных practice1 создана.

### Задание 3. Создание таблицы

   1. В левой панели раскройте practice1 → Schemas → public.
   2. Нажмите правой кнопкой на Tables → Create → Table.
   3. Вкладка General:
   1. Поле Name — введите students.
   4. Перейдите на вкладку Columns — здесь задаём поля таблицы. Заполните по порядку (каждое поле добавляется кнопкой + справа):

| № | Name | Data type | Primary key? | Not NULL? |
|---|---|---|---|---|
| 1 | id | integer | ✓ (поставьте галочку в столбце Primary key) | ✓ |
| 2 | last_name | character varying | — | ✓ |
| 3 | first_name | character varying | — | ✓ |
| 4 | group_number | character varying | — | — |
| 5 | age | integer | — | — |

   1. Нажмите Save.

Результат: таблица students создана и видна в дереве под Tables.

### Задание 4. Настройка автоувеличения поля id

Чтобы id заполнялся сам при добавлении записи:

   1. Нажмите правой кнопкой на таблицу students → Properties.
   2. Перейдите на вкладку Columns.
   3. Выделите строку id и нажмите кнопку Edit (иконка карандаша).
   4. В поле Identity выберите By Default.
   5. Нажмите Save → ещё раз Save.

Результат: при добавлении записей поле id будет заполняться автоматически (1, 2, 3 …).

### ⚠️ Если не поставить автоувеличение для поля id:

   1. Поле id нельзя будет оставить пустым.
   Поскольку id — это PRIMARY KEY (первичный ключ), он обязан иметь значение, и оно должно быть уникальным. Если нет автоувеличения, база данных не придумает число сама.
   2. Придётся вручную писать номер.
   В ячейке id необходимо будет вписать число (например, 1, потом 2 и т. д.). Из-за этого легко допустить ошибку.

Типичные проблемы:

   1. Дубликат ID. Если дважды вписать 1 — pgAdmin покажет ошибку: duplicate key value violates unique constraint. Запись не сохранится.
   2. Пропуск номеров. Можно случайно написать 1, потом сразу 3 — пропустив 2. Это не ошибка базы, но нумерация станет «рваной».
   3. Неправильный порядок. Если сначала добавить 5, а потом 1 — база примет, но логика нумерации теряется.
   4. Риск сломать работу в команде. Если два человека одновременно добавляют строки и оба ставят id = 100, один из них получит ошибку, и придётся разбираться, кто «занял» этот номер.

В PostgreSQL автоувеличение — это механизм: за кулисами создаётся отдельная последовательность под названием SEQUENCE, которая помнит: «последнее выданное число — 7, значит, следующее будет 8». И при вставке ставит это число автоматически. Без него такой «счётчик» никто не ведёт.
Как это выглядит в pgAdmin, если автоувеличения нет:
Когда нажимаем «добавить строку» и оставляем id пустым, а потом нажимаем «сохранить»:

* Вариант А (если стоит NOT NULL + PRIMARY KEY, но нет DEFAULT/Identity): Сразу ошибка: null value in column "id" violates not-null constraint. Сохранить не получится.
* Вариант Б (если NOT NULL нет, но есть PRIMARY KEY): Ошибка всё равно будет: duplicate key value violates unique constraint либо null value in column "id" violates not-null constraint — в зависимости от точной настройки.

То есть база явно не позволит иметь «пустой» первичный ключ.

### Задание 5. Добавление записей

   1. В левой панели нажмите правой кнопкой на таблицу students → View/Edit Data → All Rows.
   2. Справа откроется таблица (похожа на Excel).
   3. Заполняйте строки прямо в ячейках. Поле id оставляйте пустым — оно заполнится само при сохранении.

Введите три строки:

| id | last_name | first_name | group_number | age |
|---|---|---|---|---|
| (пусто) | Иванов | Иван | ИВ-101 | 19 |
| (пусто) | Петрова | Мария | ИВ-101 | 20 |
| (пусто) | Сидоров | Алексей | ИВ-102 | 21 |


   1. Нажмите кнопку Save Data Changes (иконка дискеты на панели сверху) или Ctrl+S.
   2. Поле id автоматически заполнится значениями 1, 2, 3.

Результат: в таблице три записи.

### Задание 6. Изменение записи

   1. Прямо в таблице найдите строку с Ивановым.
   2. Измените значение в столбце age с 19 на 22.
   3. Нажмите Save Data Changes (иконка дискеты).

Результат: запись обновлена.

### Задание 7. Удаление записи

   1. Кликните по записи с Сидоровым — вся строка выделится.
   2. Нажмите правой кнопкой по выделенной строке → Delete Row (или клавишу Delete).
   3. Нажмите Save Data Changes.

Результат: запись удалена, в таблице осталось две строки.
